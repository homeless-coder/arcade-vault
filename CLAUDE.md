## Project

Arcade Vault: a platform for playing games online and competing for the highest score (see README.md, in Spanish). This is a freshly scaffolded Next.js app (App Router) — currently just the `create-next-app` boilerplate in `app/page.tsx`.

The project intends to follow Spec Driven Design using the `/spec` and `/spec-impl` skills from https://github.com/Klerith/fernando-skills (installed via `npx skills@latest add Klerith/fernando-skills`). No specs exist yet in the repo.

## Important: this is not the Next.js you know

This repo pins **Next.js 16.3.2**, React 19.2.8 — versions newer than this model's training data, with breaking API/convention changes. Before writing Next.js code, read the relevant guide under `node_modules/next/dist/docs/` (sections: `01-app`, `02-pages`, `03-architecture`, `04-community`). Do not assume older Next.js patterns (e.g. Pages Router idioms, older routing/layout prop shapes) still apply — verify against the bundled docs first.

Evidence of the new conventions already in this codebase:
- `app/layout.tsx` types its root layout props as `LayoutProps<"/">` (a generated, route-aware type from `.next/types`), not a hand-written `{ children: React.ReactNode }`.

The AGENTS.md warning banner is regenerated by `next dev` (see `node_modules/next/dist/server/lib/generate-agent-files.js`). If it shows as a diff, that's expected — leave it in place; removing it from a commit just causes it to reappear on the next `next dev` run.

## Architecture notes

- App Router only (`app/` directory), TypeScript, Tailwind CSS v4 (via `@tailwindcss/postcss`, configured through `postcss.config.mjs`, no separate `tailwind.config.*` file).
- Path alias `@/*` maps to the repo root (`tsconfig.json`).
- ESLint uses the flat-config format with `eslint-config-next`'s `core-web-vitals` and `typescript` presets.
